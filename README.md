# 🅿️ ParkIn

**ParkIn** is a smart, ticketless parking management system that replaces physical tickets and payment terminals with an all-in-one Android application.

## 🚀 Key Features

* **NFC Entry & Exit:** Tap-to-enter and tap-to-exit access via Android devices.
* **Automated Payments:** Calculates total fare based on real-time parking duration.
* **Gate Control:** Hardware integration to physically operate barrier gates.
* **Digital Receipts:** Automatic email receipt delivery upon exit.

## 🛠️ Tech Stack

* **Mobile:** Kotlin | Jetpack Compose | Android NFC API
* **Backend:** Supabase (Database & Session Logic)
* **Hardware:** Arduino (Physical Barrier Automation)
* **Email:** Resend (Transactional Email Receipts)
